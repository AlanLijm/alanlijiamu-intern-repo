# VS Code Productivity Shortcuts

## Top 10+ Shortcuts (Windows)

### Navigation
1. **Ctrl + P** — Quick Open: jump straight to any file by typing its name, no need to click through folders.
2. **Ctrl + Tab** — Switch between recently opened files/tabs.
3. **Ctrl + G** — Go to a specific line number in the current file.

### Editing
1. **Ctrl + Alt + ↑ / ↓** — Add multiple cursors above/below the current line (multi-cursor editing).
2. **Ctrl + D** — Select the next occurrence of the current word (great for renaming repeated variables one click at a time).
3. **Alt + ↑ / ↓** — Move the current line up or down.
4. **Ctrl + /** — Toggle line comment.
5. **Shift + Alt + ↓** — Duplicate the current line/selection.

### Debugging
1. **F5** — Start debugging / continue.
2. **F9** — Toggle breakpoint on the current line.
3. **F10 / F11** — Step over / step into during debugging.

### Terminal Commands
1. **Ctrl + `** — Toggle the integrated terminal open/closed.
2. **Ctrl + Shift + `** — Open a new terminal instance.

## Which shortcuts will be most useful in my daily work?

**Multi-cursor editing (Ctrl + Alt + ↑/↓ and Ctrl + D)** will probably save me the most time — instead of manually editing the same pattern on several lines (e.g. renaming a variable used across a file, or adding the same prefix to multiple lines), I can select them all at once and type the change once. **Ctrl + P** is also going to become second nature quickly, since jumping between files by name is much faster than browsing the file tree, especially in a project with many nested folders like this onboarding repo.

## How can keyboard shortcuts improve productivity?

Keyboard shortcuts remove the small but constant friction of reaching for the mouse to click through menus, file trees, or line numbers. Individually each shortcut saves only a second or two, but across a full day of coding those seconds add up — and more importantly, staying on the keyboard keeps me in a flow state instead of breaking concentration to hunt for a button. Multi-cursor editing in particular turns what would be several repetitive manual edits into a single action, reducing both time spent and the chance of missing one instance by hand.
