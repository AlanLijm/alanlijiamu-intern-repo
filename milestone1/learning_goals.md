# 1.4 Set your learning goals

What Do You Want to Learn & Contribute?
What do you hope to learn from this internship?

I hope to get real hands-on experience with backend development in a production-style codebase — things that are hard to fully learn from university coursework alone, like working with Git workflows in a team, handling merge conflicts, code review processes, and how a real product evolves based on user feedback and bug reports. I also hope to develop stronger communication skills and learn how to work effectively as part of a team, since most of my prior experience has been on individual coursework. Beyond that, I'd like to understand how the concepts I've learned in my degree  are actually applied in a real industry environment, rather than just in an academic setting.

What skills are you most excited to develop?

I'm most excited to strengthen my backend development skills (NestJS, API design, database work) and get better at collaborative software engineering practices — Git branching strategies, writing clear commits, and working through issues in a structured, milestone-based way. 

What do you think you can contribute to the team?

I see myself as more of a doer than a talker — I'd rather be told clearly what needs to be done and then get it done efficiently, than spend a lot of time discussing or theorizing. I bring a structured, detail-oriented approach to tasks — breaking work down into clear steps and following through carefully rather than rushing. I also tend to engage critically with instructions and existing solutions rather than accepting them at face value, which I think is useful for spotting bugs, inconsistencies, or areas for improvement (as I found during the app testing assignment).

What is one area you feel less confident in that you'd like to improve?

When I'm faced with something unfamiliar, I tend to get nervous and anxious rather than diving in confidently. I'd like to build more confidence as a developer — to be able to approach unfamiliar tools, codebases, or problems calmly and trust that I can figure them out, instead of feeling anxious before I've even started.

What does success in this internship look like for you?

Success for me looks like finishing the onboarding process with a solid, practical understanding of the team's tools and workflow, being able to contribute real, working code to the Focus Bear app with minimal hand-holding, and leaving with skills and habits (structured Git use, clear documentation, critical testing mindset) that I can carry into future software engineering roles. I also want to try my best to complete all the Focus Bear tasks to a high standard, so that by the end I can give a satisfying answer — to myself, to the company, and to my university — that I made the most of this internship.
