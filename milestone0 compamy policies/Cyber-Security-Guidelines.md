# 0.7 Cyber Security Guidelines

Research & Learn

Common cyber security threats in a remote work environment Working outside a controlled office network raises the risk of phishing emails, unsecured public/home Wi-Fi, malware from personal devices, lost or stolen laptops/phones, and credential-stuffing attacks where leaked passwords from other sites are reused to break into work accounts.

Best practices for keeping devices and accounts secure Keep the OS and apps updated, use full-disk encryption, install antivirus/endpoint protection, use a unique strong password per account (via a password manager), enable 2FA everywhere it's offered, avoid installing software from untrusted sources, and use a VPN on public networks.

Why lock your computer when away from your desk An unlocked device gives anyone nearby instant access to email, code repositories, and company systems without needing any password at all — locking the screen closes that window completely, even for a "quick coffee break."

Handling phishing attempts and suspicious links Don't click links or open attachments from unexpected or unfamiliar senders; check the sender's actual email address, hover over links to preview the real URL before clicking, and report suspicious messages to a team lead/IT rather than replying or forwarding. When in doubt, verify through a separate channel (e.g. Slack) instead of trusting the email itself.

What makes a strong password, and why use a password manager A strong password is long (12+ characters), random, and unique per site — not a reused word/phrase with minor tweaks. Humans can't realistically memorize dozens of such passwords, so a password manager generates and stores them, meaning one strong master password protects everything else instead of one weak password being reused everywhere.

Why 2FA is important, and when to enable it 2FA means a stolen or guessed password alone isn't enough to log in — the attacker also needs the second factor (an app code, security key, etc.). It should be enabled on anything sensitive: email, GitHub, cloud storage, banking, and any work system that supports it, since email and GitHub in particular are gateways to resetting or accessing everything else.

Reflection

What security measures do I currently follow, and where can I improve? Honestly, not many yet — I currently just memorize passwords or reuse similar variations across accounts, I haven't turned on 2FA for important accounts like email/GitHub, and I don't have auto-lock set up on my computer or phone, so I rely on manually locking them. All three of these are areas I need to fix.

How can I make secure behaviour a habit rather than an afterthought? Since I'm starting from close to zero, the plan is to do the setup once (password manager, 2FA, auto-lock) so the security itself becomes automatic rather than something I have to remember every day. Once auto-lock is configured, "locking my screen" stops being a task I need to think about.

What steps will I take to ensure my passwords and accounts are secure? Set up a password manager and stop reusing similar passwords — generate a unique password for each account instead; go through my important accounts (email, GitHub, etc.) and turn on 2FA one by one; configure auto-lock on both my computer and phone so I'm not depending on remembering to lock manually.

What would I do if I suspected a security breach or suspicious activity on my account? Change the password immediately (and for any other account using that same/similar password), check for unfamiliar login sessions or devices and sign them out, turn on 2FA if it wasn't already on, and report it to my team lead/IT straight away instead of waiting to see if it resolves itself.
